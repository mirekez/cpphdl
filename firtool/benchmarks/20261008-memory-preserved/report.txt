The graph frontend preserves supported constant firtool_cpphdl::array_get
lookups as read-only memory. Native code uses static constant arrays with
indexed loads rather than per-bit mux networks. Existing explicit writable
RAM retains its transaction semantics. Nonconstant packed arrays keep their
existing lowering.

The complete helper body is checked as tokens before selecting the fast path.
Edited helpers retain ordinary C++ lowering. Index conversion, bounds and
wrapping uint64_t arithmetic are preserved; unsafe non-power-of-two index
ranges fall back to the original helper. Wide rows use multiple words.

ROM contents survive graph save/load and hierarchy linking. Legacy graph
records remain readable. Verilog output includes memory initialization;
explicit gate mapping preserves the constant values. ROM writes are rejected.
