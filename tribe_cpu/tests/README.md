# External RISC-V verification dependencies

`riscv-tools.lock.json` is the shared source of truth for the tested Spike,
riscv-tests, riscv-dv, riscv-arch-test (ACT4), Sail reference model, dtc and
riscv-opcodes revisions. The compatible architectural-test pair is ACT4 commit
`ef1f8b42be3b076138d30770f9562baad8b685b1` and Sail reference model **0.13.1**.
The Sail language compiler used to build that model is **0.20.2**; these are
different version numbers for different tools.

Install or repair the locked sources and tools from this directory:

```sh
./.load_spike.sh
./.load_sail_riscv_sim.sh
```

Fresh checkouts fetch the exact locked commit, not the remote's default branch.
Loaders may move a **clean** existing checkout to its locked commit. They refuse
to move dirty mismatched checkouts: save your edits or move that checkout aside
first. No hard resets or forced checkouts are performed. Recursive submodules
use the commits recorded by the selected parent. Mirror URL overrides retain
the same immutable revisions.

CTest runners reject mismatched existing revisions instead of silently testing
a different suite or reporting the mismatch as a skipped test. Matching-base
riscv-dv compatibility patches generated by its runner are retained. The ACT4
runner checks the actual Sail executable selected by `RISCV_HOME`/PATH (or
`TRIBE_ARCH_TEST_REF_MODEL`) **before** building the Verilator model, and its
generated-work stamp includes the suite revision and expected model version.
Updating only Sail to suit an arbitrary newer ACT4 checkout is not the repair:
install the locked pair together. ACT4's own compatibility checks stay enabled.

This lock does not replace the host toolchain or freeze every Python package.
ACT4's checked-in tool/dependency locks come from its pinned source revision;
its compiler minimum-version checks remain enabled. GCC/binutils paths and
versions are printed by the runner. An already installed Spike binary must be
rebuilt with `.load_spike.sh` when adopting a different locked Spike revision.

Offline regression tests (no external repository downloads or RTL tools needed):

```sh
python3 -B scripts/test_riscv_dependencies.py
```
